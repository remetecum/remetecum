## ¿Qué es REM?

El proyecto **REM** nació en 2022 en la Escuela Técnica de la Universidad de Mendoza como una única estación meteorológica estática. Con el paso de los años y el trabajo colaborativo de sucesivas generaciones de estudiantes, evolucionó hasta convertirse en una **red distribuida de estaciones** capaz de monitorear variables climáticas en tiempo real.

---

## 🎯 Objetivos

- Medir y registrar variables atmosféricas en tiempo real (temperatura, humedad, presión, radiación solar)
- Visualizar los datos en una plataforma web accesible y dinámica
- Expandir la red a distintos puntos del país para comparar biomas
- Fomentar el **Aprendizaje Basado en Proyectos (ABP)** en el nivel secundario técnico

---

## ⚙️ Tecnología

| Componente | Descripción |
|---|---|
| **Microcontrolador** | ESP32 |
| **Sensores** | BMP280 / BMP680, BH1750, entre otros |
| **Conectividad** | Wi-Fi · HTTPS · OTA |
| **Backend** | Flask · MySQL · Node-RED |
| **Frontend** | Dashboard web con gráficos en tiempo real |
| **Extras** | Deep sleep · Portal cautivo · MQTT |

## 🌍 Resultados y validación

Las estaciones fueron probadas tanto en laboratorio como en campo, en diversos puntos de la provincia de Mendoza. Los resultados confirmaron la correcta adquisición y transmisión de datos con **márgenes de error aceptables para fines educativos y de monitoreo**.

El sistema fue presentado en el **SASE 2025** (Simposio Argentino de Sistemas Embebidos), donde fue expuesto ante la comunidad científica y tecnológica del país.
